# CkBoo

Tema WordPress propio para [ckboo.es](https://ckboo.es), la web de DJ CkBoo (eventos privados y corporativos en Terrassa, Sant Cugat y Barcelona).

- Tema en `theme/ckboo/` (sin ACF ni customizer, fuentes autoalojadas).
- CPT `ckboo_foto` ("Fotos del slider"): título = pie de foto, imagen destacada = foto, "Orden" = posición.
- SEO en `inc/seo.php` (title, description, Open Graph, JSON-LD WebSite + Person).
- Formulario de contratación con Contact Form 7 (ID guardado en la opción `ckboo_booking_form_id`), reCAPTCHA v3, Akismet y honeypot.
